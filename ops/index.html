Noise control

Keep data source noise out of your alert channel

Silences and ignore settings only go so far. SlickFast Ops keeps DatasourceNoData and DatasourceError notices out of your alert channel. You pick where they go: a quiet channel, one summary every hour, or nowhere.

  • No data. An exporter or agent stopped reporting. The alert itself never fired.
  • Data source error. Grafana couldn't run the query, for example the database refused the connection.
  • Data that disappeared. Sometimes Grafana sends a "resolved" that only means the data went away. SlickFast Ops labels it that way, so you can tell it from a real fix.
  • Repeats. The same alert again within 10 minutes is sent once.

Security

What your IT reviewer will ask, answered

A one-page security sheet comes with every install. The short version:

Reads

A read-only Grafana key with the Viewer role. It cannot change dashboards, alert rules, users or settings. Revoke it any time.

Sends

Email through your own mail server, encrypted. Slack messages, with the card image, go to the Slack workspace you connect. Nothing else leaves unless you turn it on.

Public links, only if you want them

Board links stay on your server. If you turn on public links, that board's picture is served through api.slickfast.com with your key.

No phone home

No usage statistics are sent to us. No remote access, no automatic updates.

Verifies

Every release ships with checksums the installer checks. The installer is plain shell and the code inside is readable.

Small and removable

One container, running as a normal user (not root). One port, for Grafana and your team. Three commands remove it. Alert history keeps facts only, for 60 days.
